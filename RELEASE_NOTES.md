### Initial release

Duplicate Avid Media Composer bins and scripts by dropping an `.avb` or `.avc` file and choosing how many copies to make. Each copy gets a fresh UID. The source file and the clip and media MobIDs are preserved, and existing filenames are skipped.

Requires macOS 14 or newer. The app is ad hoc signed, so macOS may ask for approval in Privacy & Security. [Apple’s first-launch instructions](https://support.apple.com/en-us/102445)

Opening an original and copied `.avc` together in Media Composer still needs a live test.
